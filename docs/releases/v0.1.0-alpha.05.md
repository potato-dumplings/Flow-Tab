# FlowTab 0.1.0-alpha.05

## 简体中文

- 接入 Sparkle 2.9.6 和签名 GitHub Pages 更新源。
- 后台发现新版本时，Home 侧栏会收紧权限卡并显示圆形下载按钮。
- 新增“检查更新…”菜单，下载、安装和重启继续由 Sparkle 标准界面确认。
- 修复日志页后台持续读取解析日志导致的高 CPU。
- 本版本建立 Community Build 自动更新基线；alpha.04 用户请下载 DMG 手动覆盖安装。

## English

- Added Sparkle 2.9.6 with a signed GitHub Pages update feed.
- Home now compacts the permission card and shows a round download button when an update is available.
- Added a Check for Updates command backed by Sparkle's standard confirmation UI.
- Fixed high CPU caused by the Logs page continuing to read and parse runtime logs in the background.
- This release establishes the Community Build update baseline; alpha.04 users should install it manually from the DMG.
